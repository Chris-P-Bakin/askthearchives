What this is

The great public-domain document collections, a century of government research reports, archival records, and technical series, survive mostly as scans: photographs of pages, invisible to search and to the language models researchers now work with.

Ask the Archives transcribes these collections page by page with vision models, tags every page with its source engine and measured quality, and serves them through one public MCP endpoint: hybrid keyword-and-semantic search over section-aware chunks, full page text with provenance, figure records, page images, and ready-made citations. Every result carries its collection, so one connection searches everything.

How to connect

Claude Code or Claude Desktop:

claude mcp add --transport http archives https://mcp.askthearchives.org/mcp

Any other MCP client:

{
  "mcpServers": {
    "archives": {
      "type": "http",
      "url": "https://mcp.askthearchives.org/mcp"
    }
  }
}

No account, no key. The endpoint is rate-limited per connection and reports its own live corpus counts in the server instructions.

Tools

search
Hybrid, keyword or semantic search over the corpus; hits carry document, page span, section heading, snippet, score, source engine and quality tag.
get_page
Full text of one page with provenance (engine, quality, config hash) and a ready-made citation.
get_report
Document metadata, a link to the source archive's record, and page availability by quality.
get_figures
Structured figure records (charts, drawings, photographs) for a document or a single page; verified: false means machine-drafted.
get_page_image
The scanned page itself (PNG), optionally cropped to a bounding box.
cite
Formatted citation with stable identifiers and the source archive's URL.

Measured accuracy

Transcription quality is measured, not asserted: every collection ships with its own benchmarks against held-out human ground truth. For the NACA collection, character error rate (lower is better):

EngineMedian CER
Campaign engine (8B vision model, fine-tuned)0.0940
27B escalation lane0.0975

Retrieval is benchmarked too: hybrid search finds the right document in its top five results for 76% of held-out research questions, against 54% for whole-page embedding search. The full engine comparison lives in BENCHMARKS.md.

Caveat on tables. Agreement between engines can miss wrong digits inside numeric tables; flagged pages go through an escalation and verification lane. Treat table digits as less certain than prose, and check the page image for anything load-bearing.

Citation policy

Use the cite tool rather than composing citations by hand. Spans a transcriber could not read are marked <?> in the text; they are illegible in the original scan and must not be guessed or filled in. For hosted collections (NACA), the page images served by this archive are the citable original. For link-only collections (NARA), page images are not served; the source archive's catalog record, linked by cite, is the citable original.

Bulk download

Each collection's data releases include page images (hosted collections), transcriptions in every quality layer, figure records, errata, and the search index. Link-only collections (NARA) ship transcriptions and derived data only. Derived data is CC0. NACA batch 0 can be browsed directly: data.askthearchives.org/naca/publish/.

Transcriptions and all derived data are released CC0. NACA originals are public-domain works and their images are hosted here; NARA records are public-domain U.S. government records whose images remain with the National Archives and are linked, not hosted. Each collection names its source above. Pipeline, benchmarks, issues and questions: github.com/Chris-P-Bakin/askthearchives.
